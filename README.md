# Stock Signal Monitor

日线多因子选股、盘前计划和前向模拟账本。当前规则为 R12–1 + CMF 回调反弹策略；只做模拟，不连接券商或自动下单。

## 安装

Python 3.9+，建议使用独立虚拟环境：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
```

初始化一个未来交易日开始的新模拟账户：

```sh
stock-monitor init --config config/example.json
stock-monitor status
stock-monitor run
```

也可从仓库根目录用 `python -m stock_signal_monitor` 替代 `stock-monitor`。默认数据目录为当前目录的 `.stock-monitor/`；用 `--home /your/runtime/directory` 或 `STOCK_MONITOR_HOME` 指定。定时运行时必须使用同一个绝对数据目录。

初始化默认从下一个NYSE交易日开始，拒绝回填过去的买卖。示例配置包含2026-09-18股票池快照，**不是实时市值前100名单**。它是可编辑的研究配置，不代表对这些股票的当前推荐。因子权重在v1固定；修改权重需修改版本并另建账本。

## 规则摘要

- SPY高于200日均线；个股高于100日均线，R12–1和60日收益为正，最近3日回调、流动性及历史长度达标。
- R12–1 30%、行业相对强度20%、适度回调25%、趋势稳定性10%、CMF21 15%；宽筛选综合分数至少0.65。
- 最多5只、每行业2只，每只新仓预算为前日净值10%。没有信号就不开新仓。
- 收盘高于5日均线，或收盘低于入场价减2倍入场ATR，下一开盘退出；最长10个交易日。
- 默认10万美元模拟资金、买卖合计10bps成本，允许模拟零股。

详见 [完整规则](docs/RULES.md)。此代码不自动优化权重，分数也不是胜率。

## 数据与账本

通过yfinance下载公开Yahoo日线，无需行情账号。数据错误、过期、指纹变更会阻止新计划。下载113个标的的速度和可用性取决于数据服务；使用前请自行确认数据条款。

盘前计划保存后不可修改。收盘后仅执行开盘前已记录的计划，按开盘价代理和假定成本计算模拟成交。错过的提醒不会补造交易。结果包括已平仓净胜率、已实现/未实现盈亏、净值收益和日终最大回撤；未平仓不计胜率。

运行目录包含 `paper_ledger.sqlite`、`DAILY_STATUS.md`、每日及交易CSV、原始行情快照。它们均不随源代码发布。实际账户成绩需要实际成交记录，不能用模拟结果替代。

代码或配置升级会改变指纹；应保留旧账户，另用新数据目录开始新版本，不能通过删账重置历史。

## 调度与提醒

安装代码**不会自动创建提醒**。可用现有Codex定时任务或自己的调度器调用CLI，详见 [调度说明](docs/scheduling.md)。CLI输出JSON和本地报告，本身不发送邮件、消息或操作券商。

## 验证

```sh
python -m unittest discover -s tests -v
```

测试使用合成数据，不需要联网或下载历史数据库。覆盖因子因果性、买卖时序、风险退出跳空、分红拆股、计划不可变、重复执行、交易日历和账户核算。

## 局限

历史研究使用当前股票池，有幸存者偏差，且进行了多轮模型选择。本仓库不包含完整历史数据或声称可独立重现此前全部研究绩效。它提供选定策略的运行代码与前向模拟跟踪。

收盘触发的风险退出不保证止损价；跳空会扩大损失。模拟忽略税、现金利息、分红到账延迟和实际交易限制。新数据和独立前向结果才是后续评估依据。
