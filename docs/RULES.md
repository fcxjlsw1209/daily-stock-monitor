# R12–1 + CMF 回调反弹策略 v1

这是固定规则的研究候选和事前模拟跟踪系统，不连接券商、不自动下单。模拟资金100,000美元，每笔买卖合计成本假设0.10%（两端各0.05%）。实际账户的收益需要实际成交记录，不能用以下模拟账本替代。

## 当前选定版本

`r12_cmf_rebound_v1`；宽回调筛选 + 收复5日均线退出 + 收盘2ATR风险退出 + 最长10个交易日。

初始化时选择未来的交易日开始事前跟踪，不补记初始化前的成交。股票池固定为既有数据库2026-09-18市值快照的100家美国上市公司（含外国发行人），名单与当前行业映射保存在config.json。不是每天重新用最新市值回填过去。新规则/新股票池需要新版本，历史账本不重写。

## 每日流程和时间

America/Los_Angeles时区，周一至周五：

- 06:20，距美股常规开盘10分钟：获取上一完整交易日数据，核对已有持仓，输出当天开盘的买入、卖出和继续持有计划。可以只有1–2只或没有新买入，不凑满3–5只。
- 13:20，常规收盘20分钟后：刷新行情，按早盘已保存计划更新模拟成交和持仓，报告当日及累计结果。
- 按NYSE交易日历跳过休市，提前收盘日在13:20补记当日完整结果。时区自动处理夏令时。此代码不会自动创建定时任务，需自行配置调度。

本地任务需要电脑开机、Codex应用保持运行、网络可用。失败会明确报告；不会承诺在电脑关闭时仍能提醒。行情滞后或缺失时不发布新的交易建议，不使用旧日期冒充今天的数据。

## 1. 入围条件

每个信号日收盘后，只使用截至该日的数据：

1. 至少253个连续有效的复权收盘价观测，数据质量检查通过；过去20日平均Close×Volume大于2,000万美元。
2. SPY收盘价高于200日简单均线。
3. 股票复权收盘价高于自身100日简单均线。
4. `R12–1 = AdjClose[t−21]/AdjClose[t−252]−1 > 0`，同时过去60日复权收益为正。
5. 最近3日回调：`−3 <= z3 < 0`，其中 `z3 = 3日复权收益 / (20日日复权收益样本标准差 × √3)`。
6. 下述综合分数至少0.65，且所有所需因子数据有效。

0.65是百分位分数的加权和，不是65%胜率。

## 2. 排序因子和权重

每天在具有足够历史和流动性的股票中，分别转成横截面百分位（并列取平均名次），高分优先：

| 因子 | 定义 | 权重 |
|---|---|---:|
| R12–1 | 过去约一年收益，剔除最近21个交易日 | 30% |
| 相对行业强度 | 股票60日总回报倍数÷对应行业ETF60日总回报倍数−1 | 20% |
| 适度回调 | `−abs(z3+1.25)`，偏好适度回调，不追求最大跌幅 | 25% |
| 趋势稳定性 | 过去60日对数收益之和÷绝对对数收益之和 | 10% |
| CMF21 | 21日成交量加权收盘位置，公式见下 | 15% |

`CMF21 = sum(Volume × (2Close−High−Low)/(High−Low), 21日) / sum(Volume, 21日)`；High=Low时乘数取0。它是价量指标，不是实际机构资金流入量。

`分数 = 0.30×R12–1百分位 + 0.20×行业相对强度百分位 + 0.25×回调百分位 + 0.10×稳定性百分位 + 0.15×CMF百分位`。

## 3. 买入和仓位

- 按分数从高到低选择，最多同时持有5只；同一当前行业最多2只。不是每天新增5只。
- 每只新买入预算为前一日模拟账户收盘净值的10%，并以可用现金为上限。入场预算最多约50%，股价涨跌可能使实际仓位比例漂移。
- 已持有的不加仓；当天卖出的不重新买入。没有满足条件的股票，就不开新仓。
- 计划在当天开盘前保存，模拟成交采用当天开盘价，买入成本0.05%。数量按实际开盘价和预算计算，允许模拟零股；不是按前一天收盘价成交。
- 买入时固定记录信号日ATR14：14日简单平均True Range，True Range=max(High−Low,abs(High−前收盘),abs(Low−前收盘))。

## 4. 退出：先满足者触发

买入后，每个交易日收盘检查，满足下列任何条件则在下一交易日开盘卖出：

1. 收盘价高于自身5日简单均线，视为回调修复。
2. 收盘价低于买入价格减2倍入场时ATR14，触发风险退出。
3. 持仓达到10个交易日，于入场交易日索引加10的开盘退出。

第1、2条允许买入当日收盘触发，最早下一交易日开盘卖出。没有盘中止损、固定收益止盈或保证止损价成交；跳空下跌可以造成超过2ATR的损失。卖出成本0.05%。入场后大盘条件变差不会额外触发未经测试的退出规则。

## 5. 模拟账本与统计口径

- paper_ledger.sqlite保存不可变的盘前计划、模拟订单、已平仓交易、拆股记录和逐日净值。
- 模拟执行只有在计划于开盘前至少1分钟保存时才有效。迟到、不完整或缺失的计划不会事后补建买卖。
- 错过计划时，已有持仓继续按行情估值并处理已知分红、拆股；不虚构过去开盘卖出。错过日单独计数，因此自动化离线造成的偏差会显示出来。
- 胜率=盈利的已平仓交易数÷全部已平仓交易数；未平仓不计胜率，零收益交易不算赢。
- 总收益包括现金、持仓浮盈浮亏、已计提分红和模拟成本。已实现和未实现盈亏分开列出。暂不年化短期模拟结果。
- 分红按除息日持有资格计提，忽略到账延迟、税、ADR预提税、现金利息。新买入者不领取当日除息分红。
- 拆股调整持股数、入场参考价和ATR，原始投入成本不变。已处理成交不因Yahoo历史调整而重写；发现未处理的价格单位变化时暂停新建议并报告。
- 不把回测交易混入前向模拟胜率，不把模拟成交称为你的真实成交。你提供真实成交后，须另建实际账户记录。

## 数据和运行

每次刷新既定100家公司、SPY/QQQ和11只行业ETF最近600个日历日的Yahoo日线，检查最后日期与完整交易日一致。逐次原始快照保存在任务目录.stock-monitor/cache，计划保存快照引用和代码指纹。休市、迟到和重复执行有单独处理。

从任务根目录运行：

```sh
python -m stock_signal_monitor run
python -m stock_signal_monitor status
```

只读查看结果：DAILY_STATUS.md、daily_results.csv、closed_trades.csv、open_positions.csv、status.json。首次设置时已平仓0笔，胜率未定义；累计模拟收益0，不能提前填入回测胜率。

改变代码或config.json会触发指纹不一致检查。修复或更改规则应保留原账本并明确版本迁移，不能通过清空数据掩盖历史结果。

## 为什么只称为候选

从预先固定的3组筛选×3种退出中，按成本20bps下的跨段正收益、最少交易量、胜率和回撤标准选择。选定模型在成本10bps下2019–2026/9/18约63.9%净胜率、11.4%年化、13.3%最大日终回撤，2546笔已平仓交易。成本20bps下约61.7%胜率、7.8%年化、17.3%回撤。

股票池是当前市值前100，历史存在幸存者偏差；这些年份已经多次用于探索，选择标准也不能将它们变成独立样本外数据。该结果不是未来回报承诺。此版本是我认为值得固定规则做前向观察的候选，不能称已找到确定有效的交易优势。
